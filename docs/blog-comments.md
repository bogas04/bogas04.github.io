# Blog comments

Published blog posts use [Utterances](https://utteranc.es/) for comments. The
widget connects to the public `bogas04/bogas04.github.io` repository and maps a
post to a GitHub issue by its pathname. Utterances creates an issue when the
first comment is submitted if no matching issue exists. The repository must
have Issues enabled and the Utterances GitHub App installed for posting to
work.

Comments are stored as GitHub issue comments. Existing Disqus comments are not
automatically imported or linked to the new issues; Disqus remains a separate
archive unless its data is migrated manually.
